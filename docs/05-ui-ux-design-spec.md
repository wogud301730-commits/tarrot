# 05. UI/UX 디자인 명세

> 상위 문서: [`../PRD.md`](../PRD.md) §7. 이 문서는 세 가지 참고 이미지(럭셔리 브랜드 인트로 무드 / 신비로운 야간 풍경 인트로 / 모바일 앱 바텀시트 UI)에서 **요소만 차용해 새롭게 조합한 디자인**을 정의합니다. 어떤 이미지도 그대로 재현/모작하지 않습니다.

## 구현 범위 (Scope)

- 배경 연출 컨셉, 컬러 토큰, 타이포그래피, 컴포넌트(바텀시트/카드/버튼), 인터랙션·애니메이션 명세, 반응형 규칙을 정의한다.

## 제약 조건 (Constraints)

- 외부 이미지/폰트 CDN 의존 없이 CSS/SVG/시스템 폰트(또는 자체 호스팅 웹폰트)만 사용한다.
- 카드 아트는 저작권이 있는 실제 타로 덱 이미지를 스크래핑/복제하지 않는다 — **자체 제작한 기하학적 SVG 패턴**으로 78장을 구분한다 (`../PRD.md` §14 기본값).
- 모든 인터랙션은 마우스 없이 터치만으로 완결되어야 한다 (모바일 우선).

---

## 1. 배경 컨셉 — "은은한 금빛이 도는 밤하늘"

두 인트로 레퍼런스에서 다음 요소만 가져와 새로 조합합니다:

- 레퍼런스 A(럭셔리 브랜드 무드)에서: **절제된 여백**, 화면 하단 중앙에 작게 배치하는 진행 유도 문구, 좌상단/우상단의 아주 작은 캡션형 라벨(소문자/자간 넓은 스몰캡스) 배치 패턴.
- 레퍼런스 B(야간 풍경 무드)에서: **어두운 배경 위 중앙 하단에서 은은하게 번지는 빛(glow)**, 스크롤/사운드 토글 같은 작은 유틸리티 아이콘의 화면 모서리 배치, "탭하여 시작하세요" 류의 참여 유도형 카피 패턴.

**최종 배경 사양**:
- 배경은 세로 그라디언트: 상단 `#0B0A14`(짙은 남색-블랙) → 중하단 `#241A2E` → 화면 하단 중앙부에 `radial-gradient`로 은은한 금빛 글로우 `#E8C77E`(투명도 20~35%)가 번지는 효과.
- 그 위에 CSS로 생성한 작은 점(별) 20~40개를 무작위 위치에 배치하고 `opacity`를 3~6초 주기로 서서히 깜빡이게 한다(순수 CSS `@keyframes`, 무거운 JS 파티클 라이브러리 금지 — 성능/번들 크기 제약).
- 중앙에는 타로 카드 뒷면 실루엣(자체 제작 SVG, 얇은 금색 선으로 그린 초승달+별 문양)을 하나 배치하고, 은은한 breathing 애니메이션(`scale` 1 ↔ 1.03, 4초 주기)을 준다.
- 화면 최하단 중앙: 얇은 세리프 서체로 "터치하여 시작하기" 문구 + 아래쪽 화살표 아이콘(위아래로 bounce, 레퍼런스 B의 스크롤 유도 패턴 차용).

## 2. 컬러 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg-base` | `#0B0A14` | 전체 배경 기본색 |
| `--bg-mid` | `#241A2E` | 그라디언트 중간색 |
| `--accent-gold` | `#E8C77E` | 강조 텍스트, 글로우, 선 아트 |
| `--text-primary` | `#F5F1E8` | 본문 텍스트 (다크 배경 위) |
| `--text-muted` | `#B9AFC7` | 보조 텍스트 |
| `--surface-sheet` | `#141021` | 바텀시트 배경 |
| `--cta-black` | `#0F0E13` | 검정 pill 버튼 배경 |
| `--cta-text` | `#FFFFFF` | 버튼 텍스트 |

명도 대비: `--text-primary` on `--bg-base` ≥ 12:1, `--cta-text` on `--cta-black` ≥ 15:1 (WCAG AA/AAA 충족).

## 3. 타이포그래피

- 헤드라인/카드명: 세리프 서체(예: 시스템에 있는 `Noto Serif KR` 또는 자체 호스팅 세리프), 자간 넓게(`letter-spacing: 0.02em`), 굵기 낮게 — 레퍼런스 A의 절제된 럭셔리 무드 차용.
- 작은 라벨(예: "SCROLL", "메뉴", "사운드" 격의 유틸리티 텍스트): 대문자 + 자간 `0.15em` 이상의 산세리프 스몰캡스 — 레퍼런스 A/B 공통 패턴.
- 본문/해설 텍스트: 가독성 위주 산세리프, 16px 이상.

## 4. 컴포넌트 — 모바일 앱 바텀시트 패턴 차용

레퍼런스 C(필터/정렬/사이즈가이드 바텀시트, 검정 pill 버튼)에서 다음 패턴을 그대로 구조적으로 차용해 타로 UI에 적용합니다.

| 레퍼런스 C 요소 | 이 프로젝트에서의 적용 |
|---|---|
| 하단에서 슬라이드업되는 바텀시트 + 상단 드래그 핸들 바 | 스프레드 선택, 카드 사전 상세, "다시 뽑기 확인" 등 모든 보조 화면에 동일하게 사용 |
| 단일 선택 라디오형 리스트(Sort) | 스프레드 선택 화면 (1장/3장 중 하나 선택) |
| 필터 다중 옵션 pill 그룹(Filters) | 카드 사전의 아르카나/수트 필터 |
| 하단 고정 전체폭 검정 pill 버튼("Show 12 pieces") | "카드 뽑기 시작", "해석 다시 보기" 등 모든 주요 CTA |
| 상세 화면 정보 패널(사이즈 가이드 표) | 결과 화면의 "카드 의미 자세히 보기" 패널 |

**바텀시트 사양**:
- 모서리 반경: 상단 `24px`.
- 드래그 핸들: 너비 36px, 높이 4px, 중앙 정렬, `--text-muted` 색.
- 배경 딤(dim): `rgba(0,0,0,0.5)`, 탭 시 시트 닫힘.
- 진입 애니메이션: `transform: translateY(100%) → 0`, `transition: 280ms cubic-bezier(0.32, 0.72, 0, 1)` (iOS 스타일 시트 감속 곡선).
- 아래로 스와이프 시 임계값(시트 높이의 30%) 이상 이동하면 닫힘, 미만이면 원위치로 스냅.

**CTA 버튼 사양**:
- 전체폭(좌우 마진 16px), 높이 52px, `border-radius: 999px`, 배경 `--cta-black`, 텍스트 `--cta-text` 15px 세미볼드.
- 누르는 순간(`:active`) `scale(0.97)`로 살짝 축소되는 터치 피드백.

## 5. 카드 덱 인터랙션

- 카드 뒷면: 자체 제작 SVG(초승달+별 문양, 얇은 금색 선), 뒤집기는 3D `rotateY` CSS transform(`perspective: 1000px`)으로 구현.
- 사용자가 카드를 탭하면: 즉시 앞면이 보이는 것이 아니라 300ms의 짧은 "빛나는" 프리로딩 연출(글로우 확산) 후 플립 — 서버 응답을 기다리는 시간을 자연스럽게 감춘다.
- 이미 선택된 카드는 다시 탭할 수 없도록 비활성화 처리.

## 6. 화면별 레이아웃 요약

1. **인트로**: 전체화면 배경 + 중앙 카드 실루엣 + 하단 "터치하여 시작하기".
2. **스프레드 선택**: 배경 유지, 하단 바텀시트로 라디오 목록(1장/3장) + 하단 고정 CTA.
3. **질문 입력**: 바텀시트 내 텍스트 입력창(최대 200자 카운터 표시) + "건너뛰기"/"다음" 버튼.
4. **카드 덱**: 배경 중앙에 카드 뒷면 N장을 부채꼴 또는 가로 스크롤 그리드로 배치.
5. **결과**: 상단에 카드 결과 캐러셀(스와이프), 하단에 해설 텍스트, 최하단 고정 영역에 "카드 의미 자세히 보기"(바텀시트 트리거)와 "다시 뽑기" 버튼.
6. **카드 사전**: 상단 필터 pill(아르카나/수트), 카드 썸네일 그리드(레퍼런스 C의 상품 그리드 구조 차용), 탭 시 상세 바텀시트.

## 7. 반응형 규칙

- 기준 브레이크포인트: 375px(모바일 기본), 768px(태블릿 — 여백 확대), 1280px(데스크톱 — 중앙 정렬 최대폭 480px 컨테이너 유지, 좌우는 배경만 확장).
- 데스크톱에서도 "폰 화면 느낌"을 의도적으로 유지한다 (최대폭 480px 카드형 컨테이너를 중앙에 배치) — PRD의 "폰화면에서 터치할 수 있는 애니메이션 느낌" 요구를 데스크톱에서도 재현하기 위함.

## 완료 기준 (Definition of Done)

- [ ] 6개 화면 모두 위 레이아웃 요약대로 구현되어 있다.
- [ ] 바텀시트 컴포넌트가 스프레드 선택/카드 사전 상세/다시 뽑기 확인 등 최소 3곳에서 재사용된다(중복 구현 없음).
- [ ] 배경 애니메이션(별 깜빡임, 카드 실루엣 breathing, 글로우)이 CSS만으로 동작하고 외부 이미지 파일에 의존하지 않는다.
- [ ] 모든 CTA 버튼이 pill 스타일과 눌림 피드백을 갖는다.

## 검증 기준 (Verification)

- 실제 모바일 폭(375px) 브라우저 에뮬레이션에서 인트로부터 결과까지 전체 플로우를 터치 조작만으로 완료할 수 있는지 확인한다.
- Lighthouse 성능 점수에서 배경 애니메이션으로 인한 CLS(레이아웃 이동)가 발생하지 않는지 확인한다.
- 명도 대비 검사 도구로 `--text-primary`/`--bg-base`, `--cta-text`/`--cta-black` 조합이 WCAG AA를 충족하는지 확인한다.
- 바텀시트를 아래로 스와이프했을 때 임계값 기준대로 닫힘/원위치가 동작하는지 확인한다.
